Harness Editor

AI が 9 割つくった動画の、最後の 1 割を自分の手で直すための編集ソフトです。カット・テロップ・効果音・BGM・書き出しまで 1 画面で完結します。素材はすべて自分のパソコンの中だけで処理されるので、どこにもアップロードされません。

インストールのしかた

はじめの 1 回だけ、5 分ほどの作業があります。2 回目からはアイコンをダブルクリックするだけです。

  1. 1

    ダウンロードする

    上のボタンを押すと「ダウンロード」フォルダに ZIP ファイルが入ります。475 MB あるので、回線によっては 5〜15 分かかります。終わるまでそのまま待ってください。

  2. 2

    ZIP を開く

    ダウンロードされた Harness-Editor-0.8.2-mac-apple-silicon.zip をダブルクリックすると、隣に Harness Editor というアプリのアイコンが出てきます。

  3. 3

    「アプリケーション」フォルダへ入れる

    出てきた Harness Editor を、Finder の左側にある「アプリケーション」へドラッグして移動します。ここに入れておくと、Launchpad や Spotlight からも開けるようになります。

  4. 4

    初回だけ、Mac の確認を通す

    ここが唯一つまずくところです。ダブルクリックすると、こんな画面が出ます。

    「Harness Editor」は、開発元を確認できないため開けません。

    アプリが壊れているわけではありません。Apple に年間費用を払って登録した開発元の署名が付いていないだけで、中身は問題ありません。次の手順で通してください。

    ⚠セキュリティの確認を通す手順

    1. 出てきた画面を「完了」または「OK」でいったん閉じる
    2. 画面左上の  マーク →「システム設定」を開く
    3. 左の列から「プライバシーとセキュリティ」を選ぶ
    4. 右側を下までスクロールすると「"Harness Editor" は開発元を確認できないため、使用がブロックされました」という行がある。その右の 「このまま開く」 を押す
    5. Mac のパスワード（または Touch ID）を求められたら入力する
    6. もう一度確認が出たら 「開く」 を押す

    この作業が必要なのは 1 回目だけです。次からは普通にダブルクリックで開きます。

  5. 5

    開けたら完了

    アプリが立ち上がれば準備は終わりです。初回だけ、動画の保存先として「書類」フォルダの中に Harness Editor / Projects が作られます。

開いたあとにやること

はじめて開くと画面上でチュートリアルが出ます。読みながら 1 本つくってしまうのがいちばん早いです。

最初の 1 本の流れ

  1. ホーム画面から動画ファイルを取り込む
  2. 波形を見ながら、いらない部分をカットする（元の動画ファイルには手を加えません）
  3. テロップを置く・直す。位置と大きさはプレビュー上でドラッグできます
  4. 効果音や BGM を、タイムラインにドラッグして置く
  5. 書き出して MP4 にする。透かしは入りません

機能ごとの詳しい説明は、画面右上の「？」ボタンから写真つきで読めます。はじめてガイド も用意されています。

最初から使えないもの

次の 2 つは、アプリに同梱されていません。使う場合は別途準備が必要なので、先にお伝えしておきます。

  • 自動文字起こし — Python と音声認識モデルのセットアップが別に必要です
  • 「✦ AI で編集する」 — Claude Code（Anthropic）か Codex（OpenAI）の契約が必要です

どちらも無くても、カット・テロップ・効果音・BGM・音量調整・書き出しといった編集機能はすべて使えます。

Intel Mac・Windows をお使いの方へ

上のアプリは Apple Silicon（M1 以降）の Mac 専用です。それ以外のパソコンでは、ソース版を使います。

ソース版の入れかた

  1. こちらから ZIP をダウンロードして解凍する
  2. 解凍したフォルダの中の setup.command（Windows は setup.bat）をダブルクリック。必要なものが自動で入ります（初回のみ・数分）
  3. 終わったら start.command（Windows は start.bat）をダブルクリック。ブラウザが自動で開きます
  4. 閉じるときは、起動時に出てきた黒いウィンドウを閉じます

Windows の方へ正直にお伝えします。作者が最新版の Windows 動作を確認できていません。うまく動かないことがあるので、その時はご連絡ください。

うまくいかないとき

「壊れているため開けません」と出る

ダウンロードが途中で切れていることが多いです。アプリをゴミ箱に入れ、ZIP も削除してから、もう一度ダウンロードし直してください。

「このまま開く」のボタンが見当たらない

「プライバシーとセキュリティ」の画面を、いちばん下までスクロールしてみてください。ページの下のほうに出ます。また、この表示は一度アプリを開こうとした直後にしか出ません。見つからない場合は、先にアプリをダブルクリックしてから、もう一度システム設定を開いてください。

ダウンロードが途中で止まる

475 MB と大きいので、電波の弱い場所では止まることがあります。Wi-Fi の安定した場所で、時間を置いて試してください。上の「リンクをコピー」で URL をコピーして、ブラウザのアドレス欄に直接貼り付ける方法も使えます。

書き出した動画はどこに入る？

「書類」フォルダの中の Harness Editor / Projects の、その動画のフォルダに入ります。アプリのメニューから保存先のフォルダを直接開くこともできます。

素材や動画が外部に送られることはある？

ありません。編集も書き出しも、すべて自分のパソコンの中だけで動いています。唯一の例外は「✦ AI で編集する」を使ったときで、このときだけ依頼した文章が AI に送られます。
