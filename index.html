Harness Editor

AI 内蔵型のプレミアプロのような動画編集ソフトです。カット・テロップ・効果音・BGM・書き出しまで 1 画面で完結します。素材はすべて自分のパソコンの中だけで処理されるので、どこにもアップロードされません。

curl -fsSL https://yokoyamahayata-cyber.github.io/harness-editor-download/install.sh | bash
ダウンロード → インストール → 起動 まで、これ 1 行で終わります
バージョン 0.8.2 約 475 MB Apple Silicon Mac 専用

インストールはターミナルに 1 行貼り付けるだけです（やり方は下の手順）。Apple への年間登録をしていない開発元のアプリは、ブラウザから入れてダブルクリックすると Mac が 「壊れているため開けません」 と表示してしまうため、それを避けられるこの方法でご案内しています。アプリは壊れていません。

ZIP を直接ダウンロードしたい方・もうダウンロード済みの方

上の 1 行は、すでに「ダウンロード」フォルダに同じ ZIP がある場合はそれを使い回します。ダウンロード済みの方も、ゴミ箱に入れてしまった方も、上のコマンドをそのまま実行すれば大丈夫です（475 MB を落とし直す必要はありません）。

ZIP だけ先に受け取りたい場合はこちらです。ただし解凍してダブルクリックしても開けません。ダウンロード後に、上の 1 行を実行してください。

https://github.com/yokoyamahayata-cyber/harness-editor-download/releases/download/v0.8.2/Harness-Editor-0.8.2-mac-apple-silicon.zip

インストールのしかた

はじめの 1 回だけ、ターミナルに 1 行貼り付けます。2 回目からはアイコンをダブルクリックするだけです。

  1. 1

    ターミナルを開く

    command + スペース を押して、ターミナル と入力して Enter。黒い画面が開きます。ふだん使わないアプリですが、使うのはこの 1 回だけです。

  2. 2

    1 行貼り付けて Enter

    ページ上部の 「コマンドをコピー」 を押し、ターミナルの画面をクリックしてから command + V で貼り付け、Enter を押します。

    curl -fsSL https://yokoyamahayata-cyber.github.io/harness-editor-download/install.sh | bash
    ダウンロード → 解凍 → インストール → 制限の解除 → 起動

    このコマンドは、アプリ本体（約 475 MB）のダウンロード、「アプリケーション」フォルダへの設置、Mac がダウンロードファイルに付ける「インターネットから来た印」の削除、アプリの起動だけを行います。パスワードは不要で、何かを外部に送ることもありません。中身は install.sh で全文公開しています。

  3. 3

    終わるまで待つ

    ターミナルに進捗バーが出ます。475 MB あるので、回線によっては 5〜15 分かかります。バーが伸びていれば動いていますので、終わるまでそのままお待ちください。

    終わると インストールが終わりました。 と表示され、Harness Editor が自動で立ち上がります。初回だけ、動画の保存先として「書類」フォルダの中に Harness Editor / Projects が作られます。

    2 回目からはターミナルは不要です。「アプリケーション」フォルダや Launchpad から、普通にダブルクリックで開けます。

開いたあとにやること

はじめて開くと画面上でチュートリアルが出ます。読みながら 1 本つくってしまうのがいちばん早いです。

最初の 1 本の流れ

  1. ホーム画面から動画ファイルを取り込む
  2. 波形を見ながら、いらない部分をカットする（元の動画ファイルには手を加えません）
  3. テロップを置く・直す。位置と大きさはプレビュー上でドラッグできます
  4. 効果音や BGM を、タイムラインにドラッグして置く
  5. 書き出して MP4 にする。透かしは入りません

機能ごとの詳しい説明は、画面右上の「？」ボタンから写真つきで読めます。はじめてガイド も用意されています。

最初から使えないもの

次の 2 つは、アプリに同梱されていません。使う場合は別途準備が必要なので、先にお伝えしておきます。

  • 自動文字起こし — Python と音声認識モデルのセットアップが別に必要です
  • 「✦ AI で編集する」 — Claude Code（Anthropic）か Codex（OpenAI）の契約が必要です

どちらも無くても、カット・テロップ・効果音・BGM・音量調整・書き出しといった編集機能はすべて使えます。

Intel Mac・Windows をお使いの方へ

上のアプリは Apple Silicon（M1 以降）の Mac 専用です。それ以外のパソコンでは、ソース版を使います。

ソース版の入れかた

  1. こちらから ZIP をダウンロードして解凍する
  2. 解凍したフォルダの中の setup.command（Windows は setup.bat）をダブルクリック。必要なものが自動で入ります（初回のみ・数分）
  3. 終わったら start.command（Windows は start.bat）をダブルクリック。ブラウザが自動で開きます
  4. 閉じるときは、起動時に出てきた黒いウィンドウを閉じます

Windows の方へ正直にお伝えします。作者が最新版の Windows 動作を確認できていません。うまく動かないことがあるので、その時はご連絡ください。

うまくいかないとき

「壊れているため開けません」と出た。壊れているの？

壊れていません。Apple への年間登録（有料）をしていない開発元のアプリを、Mac がダウンロード直後に一律でブロックしているだけです。「ゴミ箱に入れる」は押さずにキャンセルし、ページ上部の 1 行コマンドを実行してください。すでにダウンロードした ZIP はそのまま使い回されるので、落とし直しは不要です。

先に「ゴミ箱に入れる」を押してしまった

そのままで大丈夫です。ページ上部の 1 行コマンドを実行すれば、ZIP から入れ直されます。ゴミ箱の中のアプリは右クリック →「削除」で捨ててかまいません。

コマンドを実行したらエラーが出た

ほとんどは通信が途中で切れた場合です。もう一度同じコマンドを実行してください。途中まで落ちた分は残っているので、続きから再開します。それでも止まる場合は、Wi-Fi の安定した場所で時間を置いてお試しください。赤い字のメッセージが出ていたら、その文面をそのままご連絡いただければ原因が分かります。

ターミナルを使わずに入れたい

残念ながら、いまの配布方法ではターミナルの 1 行が必要です。これを無くすには Apple の開発者登録（年額）での署名と公証が必要なので、対応したら改めてお知らせします。コマンドは最初の 1 回だけで、2 回目からはダブルクリックで開けます。

ダウンロードが途中で止まる

475 MB と大きいので、電波の弱い場所では止まることがあります。同じコマンドをもう一度実行すると、途中から再開します。Wi-Fi の安定した場所でお試しください。

書き出した動画はどこに入る？

「書類」フォルダの中の Harness Editor / Projects の、その動画のフォルダに入ります。アプリのメニューから保存先のフォルダを直接開くこともできます。

素材や動画が外部に送られることはある？

ありません。編集も書き出しも、すべて自分のパソコンの中だけで動いています。唯一の例外は「✦ AI で編集する」を使ったときで、このときだけ依頼した文章が AI に送られます。
